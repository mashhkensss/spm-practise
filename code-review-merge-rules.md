### Правила Code Review
1) Минимальное количество аппрувов: 1-2 (от других разработчиков, кроме автора `PR`)
2) На что обращать внимание:
	- Соответствие требованиям.
	- Архитектурная целостность (нет дублирования, соблюдены слои).
	- Качество кода (читаемость, именование, обработка ошибок).
	- Наличие тестов и их покрытие.
3) Сроки: ревью должно быть выполнено в течение 24 часов (в рабочие дни).
4) Обсуждение: комментарии должны быть конструктивными и аргументированными

### Правила Merge
1) Merge разрешён **только после**:
    - Все CI-проверки (линтер, тесты, сборка) прошли успешно.
    - Получены аппрувы.
    - Нет конфликтов с целевой веткой.
2) Удалить ветку после слияния.
