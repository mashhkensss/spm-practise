# TODO-лист

В рамках проекта создаётся TODO-лист, в котором пользователь сможет записывать свои задачки и отслеживать их выполнение. 

Возможности сервиса:
- завести задачу
- добавить к ней описание
- поставить дедлайн
- отсортировать задачи по дедлайнам
- отметить задачу выполненной
- перенести задачу на другой день
